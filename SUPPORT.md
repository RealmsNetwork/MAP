# Getting support

- **Usage/configuration:** start with the [README](README.md) and [docs](docs/).
- **Bugs:** use the Bug Report template with sanitized reproduction steps and versions.
- **Improvements:** use the Feature Request template.
- **Security:** do not use public issues; follow [SECURITY.md](SECURITY.md).

Never share API keys, bearer tokens, signed URLs, private panel hosts, or unredacted logs in public support requests.
