# Community Code of Conduct

We want the MAP community to be respectful, practical, and welcoming.

## Expected behavior

- Be respectful and constructive, including when disagreeing.
- Criticize code and ideas, not people.
- Share context and reproduce bugs when practical.
- Keep security reports and credentials private.
- Welcome contributors with different backgrounds and experience levels.

## Unacceptable behavior

Harassment, threats, discrimination, deliberate disruption, doxxing, sharing private credentials, and sustained personal attacks are not acceptable.

## Enforcement

Maintainers may remove harmful content, close discussions, or restrict participation when necessary. Reports should be sent privately to repository maintainers and will be reviewed fairly.
