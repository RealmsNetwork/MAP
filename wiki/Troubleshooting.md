# Troubleshooting

- Empty `list_panels`: configure panels and restart.
- 401/403: verify key type, namespace, and permissions.
- 404: check panel version and relative endpoint path.
- Transfer refused: trust the exact Wings hostname and verify connectivity.
- Remote HTTP blocked: use HTTPS and bearer token.
- Non-loopback startup blocked: set a random 32+ character token.

See the [full troubleshooting guide](https://github.com/RealmsNetwork/MAP/blob/main/docs/troubleshooting.md).
