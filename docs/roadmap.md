# Roadmap

This is a working direction, not a promise until implemented and tested.

## Near term

- Expand mocked coverage for API routing, authentication, redaction, and signed Wings transfers.
- Add a low-permission health/diagnostics tool.
- Improve compact summaries while preserving the generic endpoint escape hatch.
- Publish versioned releases and a tested compatibility matrix for each native panel provider and version.
- Add client configuration examples without credentials.

## Later

- Optional global read-only mode.
- Per-panel/per-tool allow/deny policies.
- Structured audit events with secret-safe redaction.
- Pagination helpers and summaries for high-volume collections.
- Improve distribution after release automation is stable.

Use issues to discuss major changes to the permission model or transport.
